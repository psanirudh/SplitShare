# SplitShare

> **An open-source web application for effortlessly tracking and splitting shared expenses.**

SplitShare helps friends, families, roommates, and teams manage shared expenses without the hassle of manual calculations. Create groups, add expenses, track balances, and easily see **who owes whom**.

## 🛠 Tech Stack

### Backend

* **.NET 10**
* **ASP.NET Core Web API**

### Frontend

* **React.js**
* Modern component-based UI architecture

### Database

* **Microsoft SQL Server**
* **Entity Framework Core** for data access and database management
